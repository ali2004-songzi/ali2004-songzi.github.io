# Notion 数据库集成说明

## 🚀 快速开始

### 第一步：创建 Notion 集成

1. 打开 https://www.notion.so/my-integrations
2. 点击「+ New integration」
3. 填写名称：「博物馆数字馆数据」
4. 选择工作区
5. 点击「Submit」
6. 复制你的 **Internal Integration Token**（以 `secret_` 开头）

### 第二步：创建数据库

在 Notion 中新建一个数据库，添加以下字段：

| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| Name | 标题 | 物种中文名 |
| ID | 文本 | 唯一标识（如 sp-001） |
| 拉丁学名 | 文本 | 学名 |
| 分类阶元 | 单选 | 界/门/纲/目/科/属/种 |
| 类别 | 单选 | animal / plant |
| 界 | 文本 | 动物界/植物界 |
| 门 | 文本 | 脊索动物门 等 |
| 纲 | 文本 | 哺乳纲 等 |
| 目 | 文本 | 食肉目 等 |
| 科 | 文本 | 猫科 等 |
| 属 | 文本 | 豹属 等 |
| 保护等级 | 单选 | LC/NT/VU/EN/CR |
| 图片 | 文件/URL | 物种图片 |
| 简介 | 文本 | 简短描述 |
| 形态特征 | 文本 | 详细描述 |
| 生态作用 | 文本 | 详细描述 |
| 生活环境 | 文本 | 详细描述 |
| 生活习性 | 文本 | 详细描述 |

### 第三步：共享数据库给集成

1. 打开你的 Notion 数据库页面
2. 点击右上角「Share」
3. 点击「Invite」
4. 搜索你刚才创建的集成名称
5. 点击「Invite」

### 第四步：获取数据库 ID

1. 打开数据库页面
2. 看浏览器地址栏，URL 格式是：
   ```
   https://www.notion.so/用户名/数据库ID?v=xxx
   ```
3. 复制那个 32 位的数据库 ID

### 第五步：配置环境变量

在项目根目录创建 `.env` 文件：

```env
NOTION_TOKEN=secret_你的token
NOTION_DATABASE_ID=你的数据库ID
```

### 第六步：同步数据

```bash
# 安装依赖
npm install @notionhq/client dotenv

# 运行同步脚本
npm run sync:notion
```

同步完成后，数据会保存到 `src/data/notion-species.json`

## 📝 数据库字段说明

### 必填字段
- **Name**：物种中文名（标题字段）
- **ID**：唯一标识，不能重复

### 分类字段
- **类别**：animal（动物）/ plant（植物）
- **界/门/纲/目/科/属**：分类层级

### 展示字段
- **拉丁学名**：斜体显示
- **保护等级**：LC/NT/VU/EN/CR
- **图片**：物种封面图
- **简介**：列表页显示
- **形态特征/生态作用/生活环境/生活习性**：详情页显示

---

## 🔄 日常使用流程

1. 在 Notion 里添加/修改物种数据
2. 运行 `npm run sync:notion`
3. 网站自动更新（热更新）

就这么简单！
